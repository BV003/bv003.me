### Why

AI agents need background documents to work well. Without them, every session starts from zero, and I end up explaining the project over and over.

So I keep these files next to the code:

```
TODO.md    # what to do next; checked items record what got done
Log.md     # what I did each day, and why
meetings/  # one file per meeting: done, doing, asks, next steps
plan/      # one file per big upcoming task: steps and what counts as done
design/    # how the system is built: classes, functions, diagrams
```
